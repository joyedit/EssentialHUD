# Essential HUD

A Vintage Story mod that displays essential player information on the HUD.

## Features

1. **Real-Time Clock** - Displays current real-world time in 12-hour format (bottom right)
2. **Block Information** - Shows the name of the block or entity you're looking at (top center)
3. **Elevation/Depth Indicator** - Displays your current Y-coordinate relative to sea level (bottom left)

## Installation

1. Build the mod using `./deploy.sh`
2. The mod will automatically be deployed to your Vintage Story mods folder
3. Launch Vintage Story and the HUD elements will appear automatically

## Building

```bash
chmod +x deploy.sh
./deploy.sh
```

## Configuration

Currently all three HUD elements are always visible. Future versions may include toggles and position customization.
